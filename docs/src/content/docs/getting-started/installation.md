---
title: Installation
description: Install the public ESM package from npm or GitHub Packages.
---

## npm

```bash
npm install @udid-tools/device-info
```

The package is ESM-only, requires Node.js 22.14 or newer for direct Node use, and works with modern
browser bundlers. It has no runtime dependencies.

## GitHub Packages

Configure the `@udid-tools` scope for GitHub Packages and authenticate according to GitHub's npm
registry documentation, then install the same package name. Every release publishes the same
verified tarball to npm and GitHub Packages.
